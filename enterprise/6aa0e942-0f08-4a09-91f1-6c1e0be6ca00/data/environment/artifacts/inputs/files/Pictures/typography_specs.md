# Typography specs - Vienna Modern press card

Studio suggestions from the design freelancer, not board approved. Ignore if
these clash with the printer's default plates. Nothing here overrides the
copy in the version 5 board approved document.

## Suggested fonts
- Display: FF Ver Sacrum (custom, hand cut). Fallback: Neutraface Text Bold.
- Body: Univers 55 Roman, 9 pt / 12 pt leading.
- Credit line: Univers 45 Light, 7.5 pt.

## Colour
- Warm gold (secession dome tone), roughly #C8A250.
- Off black text, not pure black. Roughly #1E1B18.

## Layout hints
- Full bleed cover shot top, title overlaid lower third.
- Credit line runs beneath the date block, hairline rule above.

Studio note: the header font is a nod to the Ver Sacrum lettering visible on
the Secession Building. It only reads if we keep the Secession dome cover
shot; if the cover swaps to any other shortlist candidate the display font
should shift back to a neutral sans and the header lettering rationale
falls apart.
